# SOLIS BREW — Авторская кофейня и ботаник-бар

Интерактивная витрина спешелти-напитков с живым конструктором вкуса, динамическими цветовыми темами и выдвижной корзиной.

## Особенности
- **Динамическая витрина:** крупная кинетическая фоновая типографика и плавная смена палитры под каждый напиток (`LATTE`, `MATCHA`, `FRAPPE`, `TONIC`, `BUMBLE`).
- **Режим «Утро / Закат»:** переключение атмосферы бара между дневным и вечерним освещением.
- **Конструктор напитка:** выбор объёма (`S / M / L`), молока/основы и дополнительных акцентов с мгновенным пересчётом цены.
- **Профиль вкуса:** визуальные шкалы сладости, кислинки и плотности, а также калорийность и содержание кофеина.
- **Экспресс-сомелье («Подобрать по вкусу»):** быстрый подбор напитка под настроение.
- **Выдвижная корзина:** изменение количества, апселл миндального круассана, комбо дня со скидкой 15% (промокод `SOLIS15`) и оформление заказа с номером очереди.

## Запуск локально
Проект не требует сборки — достаточно открыть `index.html` или запустить любой статический сервер:

```bash
python -m http.server 8080
```
